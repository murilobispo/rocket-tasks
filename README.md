# 🚀 Rocket Tasks

A fullstack to-do list application built for study purposes, covering the entire lifecycle of a modern web application — from authentication to a clean, functional UI.

## 💡 Idea

A task manager where users can sign up, log in with Google, and manage their personal to-do list. Simple, focused, and built with a production-like stack.

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Vite + React + TypeScript |
| UI | Shadcn/ui + Tailwind CSS |
| State / Data | TanStack Query |
| Backend | Node.js + Express + TypeScript |
| Database | PostgreSQL + Prisma |
| Auth | JWT + Google OAuth (Passport.js) |
| Validation | Zod |
| Dev | Docker Compose |
